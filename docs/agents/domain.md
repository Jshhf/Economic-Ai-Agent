# Domain Docs

This repository is treated as a single-context system.

## Layout

- root glossary: `CONTEXT.md`
- architecture decisions: `docs/adr/`

## Consumer rules

- `CONTEXT.md` defines business and platform language only
- ADRs capture architectural decisions that are meaningful, non-obvious, and costly to reverse
- implementation details should live in code, tests, and feature docs rather than the glossary
