# Issue Tracker

This repository uses local markdown for planning and tracking upgrade work.

## Location

Place implementation notes, milestones, and follow-up items under:

```text
.scratch/agent-platform-upgrade/
```

## Intended use

- capture proposed upgrades
- break large changes into small milestones
- record blocked items or future ideas

This setup is optimized for a solo project where the repo itself is the source of truth.
